⚙️ Google Auth Setup Guide

To secure this admin panel with your personal Google Account:

  1. Go to Google Cloud Console → Create Project or select existing.
  2. Navigate to APIs & Services → Credentials.
  3. Click Create Credentials → OAuth client ID (Web application).
  4. Add Authorized JavaScript Origin: http://localhost:52420.
  5. Copy your Client ID and set it in your environment: 
    export GOOGLE_CLIENT_ID="your-client-id.apps.googleusercontent.com"
